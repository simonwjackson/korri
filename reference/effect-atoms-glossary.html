Terms

Context.Service
How a service contract is declared. PascalCase class, string ID. e.g. class Library extends Context.Service<Library, LibraryShape>()("Library") {}.
Layer.succeed(Service)(value)
Provide a service from a ready value — used for harnesses, fixtures, tests. No setup effect.
Layer.effect(Service, makeEffect)
Provide a service constructed by an Effect — used for production wiring that needs setup.
Atom.make(layer)
Parks a Layer in an atom so it becomes the swap seam. Naming: <thing>LayerAtom. Override it in tests/Storybook; leave default in production.
Atom.runtime(get => ...)
Builds an executable runtime from layers read with get(layerAtom). Changing a layer atom rebuilds the runtime reactively.
runtime.atom(Effect)
A data atom (read). Produces async Result state. Naming: <noun>Atom, e.g. libraryItemsAtom.
runtime.fn()(input => Effect)
A function atom (write/command). Triggered imperatively. e.g. launchAtom.
useAtomValue(atom)
Read a data atom into React. Returns an AsyncResult-shaped value — convert it to a domain ADT before rendering.
useAtomSet(fnAtom, { mode: "promiseExit" })
Get a callable for a function atom. The result is an Exit — convert it to a command ADT (e.g. LaunchState.fromExit).
Atom.withRefresh(Duration)
Wraps a data atom to re-run on an interval (polling), self-cleaning when no readers remain. See foregroundSessionGateStateAtom.
Domain ADT
A small discriminated union (_tag) the UI understands: Loading | Ready | LoadError | Defect. Raw Result/Exit are converted into it at the hook boundary, never matched directly in JSX.
State root / self-selecting component
A Root converts the result to an ADT and provides it via context; each child state component selects its own case with Option and renders null when inactive.

Naming conventions (stack)

Service
PascalCase class — Library, Launcher.
Layer
<Service>Layer<Variant> — LibraryLayerLive, LibraryLayerInMemory.
Layer atom
<thing>LayerAtom — librarySourceLayerAtom.
Atom
<noun>Atom — libraryItemsAtom, launchAtom.
Test doubles
