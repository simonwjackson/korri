# korri-proton-ge-runtime

Packages the pinned `GE-Proton10-34` release and installs `share/korri/proton-ge-runtime/setup-env`, a sourceable shell helper for opt-in direct `wine64` launches under FEX.

This package is intentionally optional; the known-good default Mega Man Arena path remains `@korri:proton/proton-10` until GE-Proton is proven per game on Bandai.
