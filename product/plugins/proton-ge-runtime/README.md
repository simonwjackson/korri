# Proton-GE runtime plugin

Optional first-party Korri runtime plugin for pinned GloriousEggroll Proton-GE builds.

The initial runtime, `@korri:proton-ge/ge-proton-10-34`, packages the published `GE-Proton10-34.tar.gz` asset. Release notes for this version include imported aarch64 build changes, but Korri keeps this runtime opt-in until Bandai launch smoke tests prove a game works through it.
