# Super Mario Bros. Wonderland 1987 plugin

`@korri:smb-wonderland-1987` packages the public MFGG Rev 6 ZIP for **Super Mario Bros. Wonderland 1987** and exposes it as a first-party Korri catalog playable.

Upstream:

- Page: <https://mfgg.net/index.php?act=resdb&param=02&c=2&id=40985>
- Download: <https://mfgg.net/index.php?act=resdb&param=03&c=2&id=40985>
- ZIP sha256: `adedd55775e258fdee5d210618348257f6e56e573ed29cfd7067ecc7a725c399`
- Windows executable: `SMBWonderland87 (rev6).exe`

The aarch64 path follows the existing MFGG Windows fangame pattern: FEX plus Proton-GE by default, with Proton 10 as fallback.
