# RPCS3 plugin

First-party Korri plugin for Sony PlayStation 3 content discovered from JB disc folders and launched with RPCS3 on source-machine hosts.

The initial slice supports direct child game folders shaped:

```text
sony-playstation-3/
  Skate 3 [BLUS30464]/
    PS3_DISC.SFB
    PS3_GAME/
```

RPCS3 firmware and game assets are operator-supplied. The plugin must not download, bundle, or redistribute them.
