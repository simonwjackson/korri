# Psycho Waluigi plugin

First-party catalog plugin for [Psycho Waluigi](https://mfgg.net/index.php?act=resdb&param=02&c=2&id=25698) by Thunder Dragon.

Upstream publishes a Windows 32-bit MMF2-era executable zip through MFGG. The
package installs the payload read-only and launchers copy it into a writable
per-user run directory before starting Wine/FEX.
