# Community Game Catalog plugin

`@korri:community-catalog` records curated public acquisition candidates for community/fangame sources that are not yet full launch plugins.

The provider is intentionally conservative:

- direct final downloads are exposed only for stable public artifacts such as the Mega Man Rock N Roll Linux ZIP;
- itch.io pages remain delegated to the first-party itch.io provider;
- Game Jolt and pages with dynamic/manual download selection are non-final;
- source ports that require user-supplied original game data are cataloged without bypassing those requirements.
