# Odin 2 Portal Korri default launcher image

Build and host-verify a stock-based Odin 2 Portal image that installs Korri as a system launcher and makes it the default home activity through an explicit provisioning step. Preserve Android Settings, the AYN launcher as a fallback, and all AYN hardware services. Keep the bootloader unlocked. Do not write to the device without separate approval.
