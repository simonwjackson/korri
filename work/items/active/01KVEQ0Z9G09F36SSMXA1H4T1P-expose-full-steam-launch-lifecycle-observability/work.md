# Expose full Steam launch lifecycle observability

## Objective

Expose Steam launch lifecycle state as structured, bounded, UI-consumable observability so Portal and operator tooling can explain what Steam is doing during download/update, shader preparation, install scripts, cloud sync, prompts, runtime startup, game process/window readiness, exit, and cleanup.
