# Device state events foundation

Plan a Korri device-state foundation where Korrid owns normalized current device facts, exposes snapshots through RPC, and streams changes through a single Effect-aligned pipeline. Battery percentage is the first proof; future facts include Wi-Fi, presence, display, storage, Bluetooth, and related device surfaces.
