# Korri runtime session contract

Plan a unified Linux-idiomatic runtime-session contract across x86 source-machine and Nix-on-Rocks portable devices: canonical user `XDG_RUNTIME_DIR`, standard D-Bus/PipeWire/Pulse discovery, and Korri-owned state in explicit subdirectories.
