# Build a source-agnostic GMLoader plugin

Plan a first-party Korri `@korri:gmloader` plugin and launcher that accepts arbitrary local GameMaker payloads, normalizes supported shapes into a reusable GMLoader run layout, and exposes installed games through the Korri library without coupling core logic to PortMaster, itch.io, or any other source catalog.
