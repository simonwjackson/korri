# Be kind, rewind — the tape carries how you left it

> Part of the blockbuster-ps1 "meta-story / placeness" layer. Optional depth. From the first
> meta-experience batch; user liked it, with the open question of how it translates to media with
> no narrative concept — resolved below.

**Location:** the rewinder machine on the counter.

**Ritual:** some tapes are "not rewound." Load one into the console and the TV gives tracking static
and **PLEASE BE KIND — REWIND**. You stick it in the counter rewinder, crank it (hold a button while
it whirs), then it plays.

**Translation to non-narrative media (the open question):** a tape's "state" was never about story
position — it's about **how you left the object**. Rewound = put away properly; not-rewound = you
bailed mid-session last time. This works for any game regardless of genre, because the continuity is
in *your treatment of the object*, not the media's content.

**Placeness:** a small **ritual tied to a location (prop 4)** + object continuity across visits. Makes
the tape a real thing with a remembered state, and gives the counter a reason to exist.

**Notes:** sibling to [[returns-chute-refiled-by-staff]] and [[misfiled-tape-restore-store-order]]
(the tape-as-stateful-object family). Could double as a "resume vs. start over" affordance.
