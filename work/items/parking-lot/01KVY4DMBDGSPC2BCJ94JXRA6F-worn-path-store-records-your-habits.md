# The worn path — the store physically records your habits

> Part of the blockbuster-ps1 "meta-story / placeness" layer. Optional depth — the fast
> path stays fast; this rewards return.

**Location:** the carpet and the shelf edges.

**Return ritual:** the more you walk a route and pull from the same shelves over many visits,
the carpet wears a visible desire-path and those boxes get finger-softened corners and faded
spine tags. The store slowly engraves *your* habits; walking in, you can read your own history
in the floor.

**Placeness (Harrison & Dourish four-property lens):** the purest expression of the essay's
thesis — the environment accumulates the memory of use. Reinforces **stable spatial layout
(prop 1)**: layout isn't just stable, it's marked by you over time. Develops only through
return, so it can be designed *for* but not *in*.

**Notes:** depends on persistence across sessions (the deferred "go home / come back" loop is
the clock these rituals run on). Cheap to fake early with a static wear map seeded from play
counts.
